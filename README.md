# Lincoln Print Lab

Static site for lincolnprintlab.com — local PLA 3D print quotes in Lincoln, NE.

Sister brand to Nebraska Comics. Instant STL/3MF quote tool in the browser; orders by text to 402-413-5332.

## Pricing (editable in `index.html`)

- $5 setup
- $0.15 / g PLA
- $1 / print hour (~12 g/hr)
- $10 minimum
